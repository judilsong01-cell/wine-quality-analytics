# Kaggle Publication Material

## Suggested title

Red Wine Quality: A Careful Exploratory Analysis

## Subtitle

Exploratory analysis of physicochemical measures and wine quality; repeated measurements are retained.

## Short description

A reproducible R-based exploratory analysis focused on data quality, transparent preparation and decision-relevant findings.

## Full description

This project uses a local, reproducible R pipeline that starts with the original dataset, records quality checks, produces a clean analytical dataset, exports supporting tables and generates purposeful charts. The Kaggle notebook should present the narrative—not an unedited copy of internal scripts—and should recalculate all displayed values from the Kaggle input.

## Suggested tags

R, data-cleaning, exploratory-data-analysis, data-visualization, portfolio

## Questions analysed

- What are the dataset dimensions, types, missingness and exact duplicate count?
- Which quality patterns are most useful for further investigation?
- Which limitations constrain interpretation?

## Main findings

Use only values regenerated in `07_TABELAS`. Verify input version before adding findings to Kaggle; no finding is prefilled here.

## Limitations

Observational analysis cannot establish causality. Dataset source, licence, sampling and field definitions require separate verification.
